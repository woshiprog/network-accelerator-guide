# network-accelerator-guide

网络加速工具使用与连接问题排查指南。当前站点围绕虎跃加速器下载、使用、安全检查，以及游戏、视频、社交、远程办公和跨境业务网络问题组织内容。

## 站点地址

https://woshiprog.github.io/network-accelerator-guide/

## 页面

- 首页：任务分流与指标说明
- 虎跃加速器概览：官方功能与需要自行验证的实际效果
- 虎跃下载：官方入口、平台与安装来源检查
- 虎跃使用：连接、模式、线路与常见故障
- 虎跃安全：公开事实、官方隐私声明与未独立验证项
- 游戏网络：RTT、抖动、丢包和 A/B 测试
- 视频网络：持续吞吐、缓冲与线路排查
- 社交软件：通知、媒体、语音和视频分层排查
- 远程办公：会议、上行、上传、VPN/加速工具对照
- 跨境业务：按登录、编辑、上传、保存、沟通等业务动作排查
- About / Contact / 404：站点用途、纠错入口与错误页

## 内容原则

1. 每页围绕一个主要任务。
2. 公开事实、产品方介绍和第一手测试结论分开表述。
3. 不伪造实测、用户案例、速度、延迟或错误码。
4. 不因为页面短就删除；先判断是否能通过具体信息做强。
5. 不为了关键词变体批量制造近似页面。
